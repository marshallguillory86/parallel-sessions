# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep technical disagreement technical. Personal attacks, harassment, and discrimination are not welcome.

## Reporting

Email **marshallguillory@gmail.com**. Reports are confidential. Responses are best-effort from a single maintainer.
